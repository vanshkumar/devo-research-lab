# Public archive scope

The human requested public Git publication of this lab folder on November 6, 2026. The public archive preserves lab documentation, analysis code, figures, and selected compact result, protocol, provenance, and review records. The local workspace also contains substantial source data and execution assets that are deliberately not uploaded.

## Material retained locally

The [.gitignore](.gitignore) records the exclusions. These include downloaded source/input/data directories; participant-level table formats; numerical arrays and model checkpoints; archives, copied publications and source payloads; installed environments and dependencies; local application configuration; private native goal, usage, heartbeat and chat receipts; raw execution logs; and individually listed bulky or source-bearing files.

Ignoring a file does not delete or modify it. Original sources, local results, failed versions, and exposure histories remain in the workspace. The public snapshot does not claim to be a byte-for-byte backup of the roughly 11 GB local folder. Selected result records can include previously reported study-level or deidentified unit-level summaries; they do not confer permission to inspect any restricted underlying observations.

## Reading and reproduction

The retrospective links to the final relevant reports and reviews. Historical documents keep their original wording and relative links; some links target intentionally omitted local artifacts. Those missing targets are not evidence that an analysis was unperformed. Conversely, a saved receipt, code file, or hash is not evidence that a scientific claim is valid.

Use each study's source pins, requirements files, protocol, reproduction instructions, and exposure records. A clean checkout lacks the original Python environments and many inputs and intermediate arrays, so historical commands may not run without setup. This publication performs document, inclusion, and repository checks; it does not rerun scientific experiments or certify clean-checkout numerical reproduction.

The public archive adds no blanket license or claim of ownership over third-party sources. Existing source attribution and any applicable original licenses remain relevant. The manuscript is an unpublished draft; public archiving of it is not journal submission or a claim of peer review.
