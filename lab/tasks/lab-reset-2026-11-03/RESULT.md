## Cross-policy walkthroughs

| Situation | Required decision |
| --- | --- |
| All tests would pass, but only reproduce known multistability | Decline/redesign main funding unless the proposed evidence changes a material judgment; reconstruction alone supplies no importance. |
| A narrow, precise negative could change use of a learning model | It can qualify; apply the strong alternatives and fresh independent challenge appropriate to that claim. |
| A useful developmental failure leaves a concrete removable obstacle | Consider explicit reallocation with real remaining resources and preserved failure/exposure; no silent extension. |
| Confirmation plus challenge cannot fit the available envelope | Resize or redesign the scientific comparison, or defer; do not declare a tiny runnable test sufficient. |
| The same three source/design routes are closed and no new object exists | Preserve the current investment hold and zero allocation; do not rename the old search. |
| PI context grows unwieldy | Transfer sole ownership and exact unfinished objective/accounting through supported authorized controls; keep the same program and remaining evidence requirements. |
| No defensible valuable executable next experiment is justified | Record serious rejected options and reopening evidence; a scientific stop above reserve is permitted without claiming goal completion. |
| Reserve is reached despite a valuable next test | Stop science, checkpoint active work and pause/read back the same heartbeat. |
| Timer fires on an unchanged pause | Exit quietly; recovered allowance or completed administration does not resume science. |

No new scientific evidence was generated by this reset. Its success criterion is a coherent operating process and accurate current investment record, not achievement of the research mission.
