# Cheap contribution falsifier, before calculation

Written 2026-11-02, after the registered START and primary-paper inspection, before executing the reference. This is a reference screen, not a main freeze or a proposed novel theorem.

The concrete decision is whether to construct a learned correction objective before choosing a better reachable output. The strong alternative is to spend the same evaluative labels directly on the reachable candidates. Ren, Liu and Shroff (ICML 2020), sections 1.2 and 3, already formulate active best-item selection and its noisy-comparison assumptions. Zhan et al. (ICLR 2024), Algorithm 1/Definition 2/Theorem 1, already connect robust preference optimization to target-policy coverage. Neither supplies biological semantics for the lab's sources.

Use ONE standard finite decision class for a falsifying reference: five known, exactly reachable outputs, one incumbent (item 0), and all 120 permutations of utilities {0,1/4,1/2,3/4,1}, with a uniform prior shared by every strategy. Demonstration identities alone impose no additional utility constraints. A judge returns a noiseless, time-invariant, transitive pairwise preference; each response costs one label. These are deliberately favorable assumptions, not observations or a calibrated source model. The actor/planner knows the class/prior, not the actual utility permutation. No utility values or best-item identity enter the feedback. Finite candidate generation and actuation are supplied without cost and equally available to every method; a real task would have to price them.

For budgets 0 through 4, calculate the globally optimal adaptive decision tree by exact dynamic programming over consistent permutations. Terminal actions must be certified no worse than the incumbent in EVERY remaining permutation. Compare against (i) a direct running-champion tournament starting at the incumbent and (ii) the globally best fixed, nonadaptive set of the same number of comparisons, with the same posterior and safety rule. The latter has access to all reachable pairs, making it stronger than validation restricted to demonstrations. Count its label costs in full. Use expected normalized simple regret only as a reference loss under the supplied cardinal prior; the qualitative certificate is incumbent safety. There is no empirical quality or motor-learning endpoint.

Check the dynamic program by independently replaying its tree through scalar comparisons on every permutation, checking all safety decisions, and compare the tournament's full enumeration with the order-statistic formula (5-m)/((m+1)*4), where m=budget+1. Check every full-budget policy, the zero-budget case and the incumbent-is-best null. Preserve a failed assertion or implementation pass if one occurs. No noise calibration, continuous covering, new plant, critic or old-case arrays.

Contribution rule: a passive-versus-active difference alone is ordinary preference selection, not a contribution. If the optimal adaptive safe strategy supplies no decision value beyond the direct tournament, and the proposed coverage/certification statement is already standard, CLOSE at the prior gate. Do not add structural assumptions, a new class or a more elaborate algorithm to rescue it. Even a finite discrepancy would need a material interpretation beyond this reference before a main claim could be frozen. No further empirical acquisition or source reinterpretation is permitted.
