# Assumptions and sharpness of the finite-horizon calculation

These statements concern only the deterministic skill dynamics in PROTOCOL.md. They do not identify a biological state, validate a recording guarantee, or convert finite stochastic response samples into exact means.

For source block length n and learning gain a, the pre-update skill at event j+1 is 1-(1-a)^j. With retained certificates (0,1), a first retained event at the initial opportunity is always available, and the last event is successful exactly when a>=1-2^(-1/(n-1)). Thus the certificate-only admissible gain interval is [1-2^(-1/(n-1)),1]. Last-event retention and the known source block boundaries are essential assumptions.

A compulsory calibrated endpoint s fixes a=1-(1-s)^(1/n). At s=3/4 the certificate at event j+1 is successful iff2j>=n, so retaining first and last events gives the observed(0,1) for every integer n>=2. This also treats the exact score1/2 boundary analytically instead of relying on floating rounding. Every allowed count pair n_A,n_B>=2, n_A+n_B<=4+K is attainable. One admissible unknown outcome-dependent recorder is: retain an event when(first-in-block AND Y=0) OR(last-in-block AND Y=1), otherwise omit it. The selector can use the source's block-end flag; it supplies no extra state or future answers to the learner or target forecaster. This is realized deterministic compatibility, not inverse-probability weighting.

Under the main shared-retention model, the target skill z_j before a task's(j+1)st appearance obeys z_0=0 and z_(j+1)=rho[a+(1-a)z_j]. Consequently z_j=a*rho*sum_{i=0}^{j-1}[rho(1-a)]^i. The target is(1/12)sum_{a in{a_A,a_B}}sum_{j=0}^{5}z_j. The event-by-event implementation verifies this formula separately.

For0<=a,rho<=1, z_j stays in[0,1]. The map rho[a+(1-a)z] is increasing in z and rho, and its partial derivative in a is rho(1-z)>=0. Induction therefore proves that every target score is nondecreasing in a_A,a_B,rho. Conditional on calibrated source endpoints and integer counts, the gains are fixed and rho ranges continuously over[1/2,1]. The target's image is the closed interval between its two endpoint values; every point is realized by continuity. The main source set is the finite union of those intervals, not a statistical confidence interval. The saved output explicitly merges only overlapping intervals. Extremizing over the finite count set gives sharp extrema with the saved source/recorder witnesses.

A complete blocked source log and the two own-task endpoint probes leave rho free: B is still at zero throughout the A block, and the own-task B trajectory during its block is independent of A's lost state. The saved counts(3,3) witnesses match all complete source own-task scores/certificates for rho=.5 and1. They differ on the target. Thus this lack of action/history support persists even when K=0; missing histories and unsupported transitions are distinct.

The calibrated A return probe is r=s_A*rho^n_B. Conditional on counts and s_A>0, rho=(r/s_A)^(1/n_B), including the limiting zero-retention case if the parameter domain is widened to include zero. With counts unknown, every feasible count pair yields one target point. Re-auditing any retained certificate has likelihood1 for the known value under every admissible world; it cannot reveal unrecorded practice or shrink this set. A total-count audit supplies a different observation. These are observation-likelihood claims about the defined deterministic experiment, not claims about a random audit of hidden events.

For worst-case return-probe precision, count pair i is feasible iff r>=s_A*(1/2)^n_B. Between consecutive such thresholds the feasible count set is fixed, and each T_i(r) is nondecreasing. For any subinterval[l,u],

This proves the envelope used by main.py in exact arithmetic. Within-cell subdivisions yield conservative upper bounds; actual observations and two same-observation witnesses supply attained lower bounds. Threshold observations are evaluated with their complete feasible count set; a branch entering at a threshold is not incorrectly extrapolated into earlier observations. Global upper-minus-attained gaps are saved. The implementation uses ordinary floating arithmetic with a1e-11guard and80-digit/root/event checks, not formal directed rounding. If EVERY successful source event is retained, the calibrated s=3/4block has floor(n/2)successful pre-update events. The recorded block has exactly one success, so n is2or3. This yields a smaller count set than an arbitrary-omission guarantee. Explicit position enumeration independently checks this restriction. Its much narrower return-probe bound depends on this additional logging guarantee; it is not earned from observing only successful records.

A binary A return certificate partitions rho at(2/3)^(1/n_B). The Y=0partition is open at its upper boundary; reported upper values there are suprema, not falsely claimed attaining endpoints. The primary calibrated-score results have closed/attained parameter sets.

For score errors bounded by epsilon, a_A and rho are linked through the same unknown s_A. Treating their independent marginal extrema as simultaneously attainable would be wrong. The saved calibration analysis subdivides s_A, uses coordinate monotonicity to enclose each box, and saves actual feasible score/rate witnesses. Its enclosures are explicitly labeled nonsharp, and reference grids check feasible coupled triples. They describe bounded deterministic calibration errors, not coverage probabilities.

## Postvalidation directional contrary test

Let rho_A govern loss of A on a B event, and rho_B loss of B on an A event. The complete A-then-B source, own-task endpoint probes and A return observe rho_A only: B is zero during the initial A block, so rho_B never affects any source observation. Keeping n_A=n_B=3, both gains1-4^(-1/3), and rho_A=.75, all rho_B in[.5,1] are compatible. The target is the average of one univariate target trace with rho_A and one with rho_B. Coordinate monotonicity proves its endpoints at rho_B=.5and1 are sharp and attained. The two saved witnesses differ by0.1866519841on the target despite identical source and A-return observations.

After the source/A-return, ONE known A teaching event changes B from s_B to q_B=rho_B*s_B. A compulsory nonlearning B score probe therefore identifies rho_B=q_B/s_B, while the earlier return identifies rho_A. The intervention's A-state update does not contaminate this B ratio under the declared dynamics. Both extrema are explicitly recovered. This is a costed additional intervention/measurement, not information contained in the original archive and not proof that a biological probe is nonlearning or that interference is state-independent.
