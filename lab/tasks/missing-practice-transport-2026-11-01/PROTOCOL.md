## Model and object

Two skill states start at zero: x_A=x_B=0. A teaching event of task a updates x_a <- x_a + alpha_a(1-x_a) and x_other <- rho*x_other. Gains alpha_A,alpha_B are fixed in (0,1]; shared cross-task retention rho is in [1/2,1]. No passive decay, heterogeneous gains within a person, transfer gains, state-dependent retention or probe-induced learning. A calibrated nonteaching probe reads x_a on a known common scale. These are synthetic assumptions, not biological facts. The credible restricted alternative is rho=1 (no cross-task loss); no policy-specific parameters are fitted.

Source: one A block followed by one B block, with two retained teaching events per task. Retained certificates are (0,1) in each block, where Y=1[x_a>=1/2] is read BEFORE updating. The last event of each block is retained; its first retained event's position is unknown. Unknown recording may depend arbitrarily on action, certificate, event history and block-end flag. It has no probability model. It is shared as a realized source recording mechanism, not transported to the target. There is no inference from merely positive likelihood under finite Bernoulli sampling: the class is deterministic and compatibility is logical.

An independent logging guarantee bounds the TOTAL unrecorded teaching events h_A+h_B<=K, so integer n_A,n_B>=2 and n_A+n_B<=4+K. This guarantee and the two-block action restriction cover actual practice, not just recorded data. K=0,1,2,3,4,8 are predeclared; primary allocation is K=4. New policies cannot add unmodeled practice. Teacher and observation clocks are assumed correct.

Target: mean pre-update calibrated skill during 12 teaching opportunities, schedule ABABABABABAB, from a fresh zero state with the same gains/retention. It is a skill-scale forecast, not a Bernoulli success probability or causal effect in an empirical population. A diameter <=0.10 of this known [0,1] scale is the practical precision criterion. It is a chosen design criterion, not an earned biological equivalence margin.

## Analysis and reliability

Use closed-form skill trajectories and a separate event-by-event simulator. For given alpha/rho, the jth pre-update skill on either task in the target is alpha*rho*sum_{i=0}^{j-1}[rho(1-alpha)]^i, j=0..5. Target is the average over both tasks. Prove coordinate monotonicity and use it only under its stated parameter domain. Exact source D eliminates continuous alpha conditional on counts. For each count pair rho maps monotonically to a target interval; all endpoints need explicit admissible history/selector witnesses. Report disconnected unions rather than filling gaps silently.

Worst-case score-probe design: split the possible score range at every feasibility threshold s_A*(1/2)^n_B. On any resulting interval the feasible count set is fixed. Each count-specific target is increasing in r. For a box [l,u], max_i T_i(u)-min_i T_i(l) is a conservative upper bound on the within-observation diameter; evaluated interior/endpoint observations provide attained lower bounds. Refine the largest possible upper bound until the global gap is <=1e-5 or 50,000 boxes; retain bounds/tolerances if stopped. Floating results will be checked against high-precision arithmetic on extrema and difficult boundaries; no formal interval library or general computational theorem is claimed.

Controls: rho=1 closed-form independent calculation; rho=0 limiting target zero; known counts/gains/retention point recovery; incompatible source endpoint/count and incompatible return scores rejected; small brute-force omitted-position reconstruction separate from analytic compatibility; full complete-source-log witnesses with different rho; exact outcome-likelihood partitions for each measurement.
