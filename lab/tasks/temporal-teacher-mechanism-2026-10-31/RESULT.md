# Temporal teacher mechanism: useful readout, confirmed corrective-feedback failure

A tutor-response prototype extracts useful order and timing information from the existing zero-HVC population response. It substantially improves complete motor learning over the global firing-rate readout. It remains an incomplete repair: the tutored-population prototype passes the frozen acquisition criterion in4/8new whole cases, and unchanged source equations confirm that it can reject a nearly correct duration. An explicit sensory sequence memory solves8/8, but gives exactly the same result as ordinary onset-registered template matching. No performance contribution beyond that template is demonstrated.

The mechanistic distinction is between recognizing a target and supplying reliable corrections while content is imperfect. Failure of the old averaged-rate teacher did not establish absent temporal information in the population. Conversely, making the exact tutor response a zero-distance prototype did not make all corrective feedback reliable. These are results about specific computational prescriptions, not the neural implementation in birds.
