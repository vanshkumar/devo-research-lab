# Input-only linkage diagnostic

Frozen 2026-11-05 03:26 UTC after inspecting release metadata and published protocols, before acquiring individual learner payloads. No score values are needed. This diagnostic answers whether the released inputs allow a reproducible first-feedback response proxy at Draft 2. It is a check of data and measurement, separate from the absent prospective score baseline.

- Open exactly the 24 development keys selected by the metadata rule in [LAYOUT.json](LAYOUT.json). The unit is a writer on one essay. Six keys per interface are selected using the fixed salted SHA-256 order, independent of essay, score and annotation content. The arm folders are used for sampling and descriptive stratification only. No replacement keys after observing contents or on failure.
- For each selected key open only the pinned Draft 1, Draft 2, individualized feedback DOCX, and Rev12 workbook. Check git blob identity, combine essay and annotation sentence text in order, and compare ordered case-folded Unicode word-token sequences for Old Draft against Draft 1 and New Draft against Draft 2. Check mismatches explicitly and record how exact linkage was assessed. The feedback key comes from the release filename and the protocol, with no individual delivery logs expected.
- Define demand as presence in the Word body of the published exact sentence identifying an absent rebuttal, with case and whitespace normalized. Define response proxy as at least one sentence-level Add annotated Rebuttal/Reservation in the New Draft sheet. A matching addition can be irrelevant, poor or spontaneous. Generic or milder rebuttal requests and modifications can escape this proxy. Other feedback, response categories and scoring rules are outside this calculation.
- Count eligible linked learners, provide the demand/addition contingency table, a writer-level difference in rates and a 95% Newcombe score interval when both groups are present, plus the expected overlap if the observed demand labels were randomly reassigned within interface. Conditioning here is descriptive. The groups differ in feedback selection and opportunity, so the comparison cannot estimate a feedback effect or validate uptake.
- Stop on a failure of exact development linkage without guessing a new key. Any plausible worksheet/text representation mismatch may receive a bounded forensic description. Preserve the initial counts and any corrective parser amendments. Keep all score worksheets/shared strings, every Draft 3 and Rev23 payload, and all individual files outside these 24 keys unopened.
