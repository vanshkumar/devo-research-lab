# Sources and access

Exactly TWO deliberately targeted empirical families were named in the first query: **hc-3** and **Grosmark/hc-11**. The initial query was `hippocampal sleep replay subsequent learning performance dataset Grosmark Buzsaki CRCNS hc-3`. Other returned study descriptions were incidental summary exposure, not additional screened/acquired families. No third family was pursued.

1. [CRCNS hc-3 deposit description](https://crcns.org/data-sets/hc/hc-3/about-hc-3), dataset DOI **10.6080/K09G5JRZ**. [Primary format documentation](https://crcns.org/files/data/hc3/crcns-hc3-data-description.pdf), version 1.1, July 5, 2014. Its page 2 describes Tmaze as spontaneous alternation on a rewarded T maze and Mwheel as a rewarded alternation maze plus a running wheel. Pages 4–5 describe same-day concatenated spike sorting; pages 6–9 describe the session, file and spike-count tables. These are dataset methods, not certification of trial-by-trial performance.
2. [hc-3 metadata ZIP](https://crcns.org/files/data/hc3/crcns-hc3-metadata-tables.zip), retrieved 2026-11-01T05:45:58Z. Last-Modified July 3, 2014; ETag `"5d2668-4fd50a2b7ad00"`. Acquisition stopped at the deliberately imposed 5,000,001-byte application-read boundary, so **this is a prefix, not a complete archive**. SHA256 `5e1c7dcb2c37884f2afcf67083372454aa6a6b033dd4a6eaf3ce19edc9fc551f`. Complete leading current-version members were locally decoded using their deflate end markers/data descriptors and CRCs. Their exact sizes/SHA256s are in PREFIX_INSPECTION.json; the partial old-version member was not used. No further bytes or replacement endpoint were acquired. The public documentation requests original-publication/dataset citation; an explicit SPDX license for the CRCNS files was not certified in this bounded pass. Public accessibility is not a certified redistribution license.
3. [CRCNS hc-11 description](https://crcns.org/data-sets/hc/hc-11/about-hc-11/), dataset DOI **10.6080/K0862DC5**. [Format PDF](https://crcns.org/files/data/hc-11/crcns_hc-11_data_description.pdf), version 0.8, December 7, 2016. Describes eight PRE/MAZE/POST recordings from four rats. The described POST sleep has no later maze test in the same recording. The original CRCNS download route declares an account requirement; no account was used.

The inspected primary material does not establish novelty of the proposed comparison, and this run makes no novelty claim.
