## Legitimate information

Forecasting protocol is an explicitly added observer to the original online learner. All methods know the original task law, complete preceding training inputs/labels/losses, current 111 parameters, update age, SGD settings, the announced future context and its 32 equiprobable input points. Neither target-blind predictor receives the fixed teacher parameters, new labels, subsequent SGD draws or future scores. The simulation scorer holds the teacher; this is a declared observation interface, not a claim that the experimenter physically lacks the synthetic labels. A fully informed teacher oracle would make autonomous simulation possible and is not an appropriate unknown-label forecasting problem. We do not claim this to be the only deployment information set.

Current-performance, recent acquisition history, age, weight scale, prediction moments, active/dead fraction and input-change information are available to the baseline. Random targets are generated independently of the true teacher. Any task-labelled probe is a separate explicitly privileged copy baseline; its labels, updates and scoring access are charged and never fed to the target-blind diagnostic or continuing learner.

Prior consumed teacher realizations, states and all old MNIST/protected payloads remain closed/development. No old numerical state is read. The pilot will create one new source-equation realization and immediately treat it as development. Full original 1M training history must execute; a shorter substitute cannot qualify. Source-equation Python float64/RNG is distinguished from author Torch float32/RNG execution. No proposed correction to the old renewal/mean/retention or PMNIST branches is made.

## Stop rule

Run one prespecified pilot with full original history, saved-before-feedback predictions and independent update checks. CLOSE if there is no material resolved residual, no task acquisition/forecast contrast, no useful increment over the strong baseline, or no earned compute/feedback justification. No retuning of consumed future tasks or main campaign. One pre-main revision remains unused.
