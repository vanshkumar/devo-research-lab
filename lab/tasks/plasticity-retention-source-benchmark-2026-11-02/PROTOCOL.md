# Contribution and affordability decision

**Decision: retain the original slowly changing regression benchmark for one bounded protocol-calibration allocation; do not launch a main matched-retention campaign from this gate.** A full original-size SGD stream is demonstrably cheap. Generic tradeoff novelty is closed; a particular joint functional benefit remains unearned. The main blockers are precise closest-prior coverage and executable CBP/control calibration, not a demonstrated lack of local compute.

The next investment would test whether selective renewal buys a material acquisition advantage that random renewal, shrink/perturb or simple rehearsal cannot obtain at equal or better retained old-function risk, under equal data, model capacity, storage and update opportunities. This is a specific comparison to earn, not an existing result or an attributed guarantee of the Nature paper. See PRIOR_GATE.md for actual prior scope and failed accesses.

## Source-defined problem and actual feasibility

Use the pinned author's original slowly changing regression source/configuration, not the 2025 transformer variant. There are 20 binary inputs, 15 slow inputs jointly resampled every 10,000 examples and 5 independent fast bits; the target is one fixed 100-unit LTU network. Thus each context has exactly 32 possible input points. The learner is the original 5-unit ReLU network. The slow inputs are jointly resampled in this pinned default, not silently replaced by a one-bit flip. Teacher threshold/bias and strict comparison must remain exactly as pinned; do not substitute a conventional threshold rule.

At this gate the original source-defined SGD learning equations were independently implemented in standard-library Python. The 1,000,000-update, 100-task run took 12.292169958 seconds, including 11.399321125 seconds learning/reference work, and 64,913,408 bytes peak RSS. All 3,232 teacher exact-integer checks and eight full 111-parameter finite-difference/scalar-update checkpoints passed. This certifies a cheap SGD reference stream; CBP, replay, full old-task scoring and a selected multi-stream campaign have not been timed. Python float64/RNG differ from the source's Torch float32/RNG. No exact published-curve reproduction or original-author-code execution is claimed.

## Measurement that answers the question

Keep the published input/target sequence unchanged. The scorer alone may enumerate the exact 32-point uniform fast-bit support in each realized old context; learners never receive these scoring labels. Freeze task boundaries and evaluation times in advance. A repeated slow context retains the same target and must not be treated as a novel independent task.

For task k, new acquisition is pre-update online squared error over a fixed initial window of the original 10,000 examples; report the entire within-task online curve and final whole-support error as secondary measurements. Choose that window before the new runs; do not choose it from this feasibility stream's errors. Old-function risk is mean squared error against the unchanged target on every earlier context's 32-point support, with contexts weighted equally. Report both absolute old risk and each old task's risk immediately after its initial training, so different initial competence cannot masquerade as retention. Prediction drift, weight distance, feature rank or dead-unit counts are explanatory diagnostics, not substitutes for old-function performance.

The retained old function is useful prediction on previously learned inputs, not recovery of an inaccessible latent state. This fixed global teacher has no incompatible old labels at a repeated input. All-history old-risk scoring and retention at different ages remain UNRUN at this gate.

## Strong alternatives and fairness

Minimum families are plain SGD with reservoir rehearsal; CBP with the SAME rehearsal; random eligible-unit renewal with the SAME rehearsal and replacement schedule; shrink/perturb with the SAME rehearsal. Include zero-renewal/no-replay endpoints as diagnostics. A full reset can bound reacquisition cost but cannot itself establish useful joint retention. Freeze all renewal timing, optimizer/replay ordering, maturity/utility options, storage and update counts before evaluation. Report wall time as well as learning-update count: CBP utility is not free compute.

Every arm receives the same current stream and permitted past examples, the same model architecture/initial realization, the same fixed reservoir capacity and replacement-independent reservoir random stream. Provide the same gradient opportunities on current and replay data to each arm. If replay gradients are separate steps, CBP's generate-and-test must follow the same per-gradient semantics and be charged. Optimizer/method state and replay payload count toward storage; source/scorer storage does not become free learner memory.

The 32-point context support also requires a simple bounded exact input→target cache/rehearsal control. Repeated-input memorization may trivialize short-horizon comparisons. Give that control only actually observed pairs and a clearly priced storage budget; use a bounded reservoir over the full history rather than an ever-growing table. Do not close the long-stream question merely because an unbounded table solves the finite input space. Exact labels are integers in [-101,101], but any packed representation must be priced equally and distinguished from actual Python object RSS.

## Matching, selection and uncertainty

Compare attained old-risk/acquisition points, not just the best current accuracy. A claim of useful dominance requires a material new-acquisition improvement AND no greater old-function risk within declared uncertainty. Interpolating between unachieved retention points, selecting a favorable task age/window after evaluation, or allowing extra forgetting and calling it equal retention is prohibited. If methods do not reach a common retention range, report noncomparability rather than the requested advantage.

Use separate development streams to choose a small, fixed set of intervention strengths and the common retention budget; preserve all settings tried and include equal tuning for strong simple controls. Then commit independent teacher/data/initialization seed streams before evaluation. This task's two seed-1729 streams are consumed development only and share a teacher. The independent unit is the whole teacher/stream, not its 100 tasks, 10,000 updates or 32 support points. Use paired stream differences with uncertainty, including every planned comparator; do not search a favorable frontier and then treat it as prespecified. Predeclare a material acquisition margin and retained-risk tolerance in interpretable target-variance units before seeing new evaluation outcomes. A null or sparse common support is not equivalence or absence of an effect.

Before any main launch: certify the accessed closest-prior residual, including the unresolved CVPR2024 comparison; pin the author's CBP experiment configuration and remaining import dependency (AdamGnT is imported even by the SGD CBP module); independently check the renewal/utility update; and time ONE representative original full stream with the actual replay and full old-function scorer. Use that measured rate to price a finite equally tuned comparison and a material-effect discrimination check. This is targeted same-question work, not an automatic broad source-chain repair or permission to exceed this allocation's 30 operations.

Close the proposed comparison if the precise prior already answers it, if a fair simple bounded cache/replay control makes the proposed benefit routine, if no useful matched-retention range exists, or if the earned process/usage bounds do not fit. Otherwise the PI must make a fresh allowance-backed main investment with frozen settings, sample size, margins, uncertainty and a distinct independent challenge.
