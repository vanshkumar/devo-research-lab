# Bounded input-certification check

Declared 2026-10-31 before decoding new expression values. This is an input
check, not a receptor prediction experiment. The primary comparison remains
unrun unless independent units and compatible measurements are certified.

Inspect the officially linked CELLxGENE mouse snapshot, whose current version
differs from the third-party indexed version. Pin the official asset before
sampling. Read HDF5 structure without storage-size traversal, then actual
donor/sample/batch/dataset categories and their row counts. Preserve these
distinct units; a batch or dataset is never automatically an animal.
At most nine 1 MiB physical ranges across this sample stage (9,437,184 bytes),
with the overall 40-request ceiling including five provider operations.
No whole-atlas read. Record partial failures without retries.

If input structure permits, check a few non-target numerical observations,
with the 54 original receptor symbols redacted from this certification step.
Symbol capitalization may conservatively redact a receptor; it does not certify
one-to-one orthology. No new receptor values, matching or target scoring is
authorized by this sample plan. A full prediction protocol must precede those.

Prior atlas summaries, selected receptor tables, human donors and all earlier
gene/cell exposures remain consumed. New byte ranges may carry encoded values
beyond the logical columns decoded; record both forms of access.
