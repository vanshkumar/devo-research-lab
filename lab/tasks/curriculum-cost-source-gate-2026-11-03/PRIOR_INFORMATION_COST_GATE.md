## Original task and legitimate information

Selected release: [TSCL commit ec41eea6aa45f68c183b839a3279db4c66857705](https://github.com/tambetm/TSCL/tree/ec41eea6aa45f68c183b839a3279db4c66857705), dated2017-11-24. The source uses nine digit-length subtasks by default. It generates both operands from digits (allowing leading zero generation), converts them to integers, pads/inverts the input, and supplies a padded decimal sum. The model repeats the last encoder output as decoder input; it does not transfer encoder state. The release uses Adam/lr.001/clipnorm2 in its driver; Keras/TensorFlow versions and backend defaults are not pinned by the inspected dependency list. Those are unresolved execution semantics, not permission to assume a current LSTM replacement.

The teacher legitimately gets validation accuracies for every digit length after each step; its task distribution is applied to generated training samples. Manual progression legitimately uses training completion. Uniform sampling and the published combined curriculum are substantive existing alternatives, while online/window/sampling are already simple performance-history policies. Masking these scores or charging training feedback as an extra test would change the problem. An eventual independent unit would be a whole initialized student plus its generated training/validation realization, rather than each batch or task.

## Source-grounded per-step accounting (not a measured run)

At driver defaults, one step generates40,960 training examples, trains ten batches of4,096 and then supplies per-task validation scores. A fixed4,096-example uniform validation set is generated once per environment. `train_epoch` passes it to `model.fit`; `accuracy_per_length` then invokes a separate prediction on it. Thus the release requests8,192 validation-example forward evaluations per step and zero validation gradient updates. The SAME step is called by CurriculumTeacher (uniform/manual), Naive, Online, Window and Sampling. The10 training updates, initial data generation, both validation passes, sampling/policy work and storage must be priced;8192/40960 is an example-count ratio, not a wall-time ratio. No fresh validation labels are generated every step. Repeated use may raise a general evaluation-design question, but no consequential effect of it was tested here.

Source pin/call-graph audit exits0 and verifies all four Git blob SHA1s. It checks the actual fit/validation/predict call path and shared teacher step. This is not a numerical model/scorer reconstruction or proof of scientific utility. No learner copies, weights, optimizer states or generated examples were created.
