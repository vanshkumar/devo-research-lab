# One mechanism, before development

2026-10-29. No scored synthetic controls or human responses have been read. Development is four invented original-task sequences: blocked and interleaved, seeds 11 and 12, each 160+40 stories. One proposed setting (no search): published Simulation 2 alpha=1.7026910310943673, beta=1.8476105399460376, lambda=.2112472814674634; predictability prior=.5 and symmetric two-outcome Dirichlet reliability prior=.5.

Three scientific roles only: original no-exclusion SEM, published oracle-exclusion SEM, learned reliability SEM. Native source fidelity checks additionally use original Simulation 1's published parameters. Primary matched comparison fixes all roles to Simulation 2's parameters, leaving oracle exclusion versus learned inference as the information difference. No learned location, noise flag, curriculum identity, future state or true context enters a learner.

For each observable outgoing state, compare independent Dirichlet(.5,.5) transition distributions within each *inferred* schema against fair irreducible randomness. Compute exact integrated log Bayes factors from unweighted previously observed counts; convert to a posterior predictability probability w. Pool evidence across inferred schemas, not across transitions that differ by schema. This is an explicit Bayesian discrete reliability analogue motivated by Beukers Eq.2-5 and its discussion of inferred predictability (p.10, citing Mathys2014 and Piray/Daw2021). It is not an implementation or independent verification of those cited models.

Before observing the next state, record the current-schema source transition prediction. After observing it, compute the source local-MAP candidate posterior, and mix it with a point mass on the current schema: w*P_SEM(z|transition)+(1-w)*delta_current. Select its MAP; update the chosen schema's transition counts and CRP occupancy by w. Separately record the transition with weight1 for the reliability evidence. Thus w=0 literally preserves the active schema, unlike merely flattening the likelihood and allowing the old CRP prior to recapture it. Every state uses the same rule. The first reliability prior is .5; no time step is designated random.

The source's two-possible-outcome assumption is retained symmetrically; numerical IDs convey no role. Prediction precedes outcome access and uses common source softmax(4*transition estimates) on the ordinary two candidate states. Source unnormalized nine-state output is preserved in source checks. Interpret scores as linked model choice probabilities, not categorical optimality or a fitted new human response rule.

Freeze the prescription and score protocol after this development run, before 20 new fixed-seed sequences/condition. If the approach fails, retain it and stop rather than introduce a fourth role. Human values remain prohibited.
