# Frozen scientific design — first-half blocked-to-interleaved forecast

Declared 2026-11-01 before source model fitting and before any evaluation response interpretation. This operational protocol is frozen when its SHA is saved in FREEZE.json. This is a derivative contextual-exemplar prescription, not a claimed reproduction of the fitted 2022 SAT-M implementation or a new attentional mechanism.

## Evidence and units

Use only Experiment 1's newly acquired high-similarity DAT records from public OSF s87tf/t8wzy and the six-category item map in Stim-struct.xlsx sheet High Sim. The canonical exemplars_highsim.csv contains only three categories and does not map the actual six physical categories; it is not used for individual forecasts. Treat workbook feature codes as nominal curvilinear-segment identities. Distance is a count of differing features, not a metric on arbitrary numerical segment IDs. This supplied eight-feature representation is a substantive privilege; no pixels or calibrated perceptual geometry are inferred.

Use FIRST curriculum only, with its 288 labeled training opportunities and first 48 no-feedback test opportunities. Include each complete 672-row record, without any accuracy exclusion. Exclude ID41 solely because its input record stops at 308 rows and first test is incomplete. Source people are the 22 even IDs, whose first curriculum is blocked (BI). Evaluation people are the 21 complete odd IDs, whose first curriculum is interleaved (IB). ID20's whole record is consumed development. Other people were decoded/hashed for an input-only census; their responses were not interpreted. Second curricula and old-item outcomes are auxiliary acquired/decoded material, not untouched holdouts.

Source fitting uses first-test NEW-item responses only (24/person) and all actual first-training item/feedback-label exposures. Evaluation responses stay uninterpreted until all probabilities have been saved. At evaluation, use the actual exposure order, feedback labels, test-item geometry and test opportunity order. Do not condition on or fit to evaluation training responses or any test responses. All alternatives receive these same inputs. Teacher opportunities are observed, not generated; the paper's fixed stochastic schedule is not response-adaptive. Initial instructions are supplied but the model starts with empty memory. Assignment is counterbalanced in the paper; alternating IDs in the files do not independently prove random assignment. These are conditional predictive comparisons, not a causal curriculum effect.

Map a..f stimulus category identities to response codes 0..2 by each file's first-three-group header. Verify the training supplied-correct column against this mapping; do not use test response/correctness columns in feature construction. New items are exact nonmembers of the prior training-item set, independently checked against the test-old flag at scoring. Every test response, including an invalid/missing response if present, must be accounted for; an invalid code causes a reporting stop rather than silent deletion.

## Prescriptions

P, local-context encoding: store each training exposure x with supplied label and feature-specific weight according to whether its feature equals the immediately preceding exposure's feature and whether their labels agree. Four positive weights cover same-feature/same-label, different-feature/same-label, same-feature/different-label and different-feature/different-label. Fix the last to 1; fit the other three log weights in [-2,2]. The first exposure has all weights 1. For query y, d(y,x)=sum_i epsilon(x,i)*1[y_i!=x_i]/8 and similarity exp(-c*d), with log(c) in [-4,4]. Memory weight is exp(-decay*age/288 + spacing*log(1+gap)), where age is training opportunities since exposure and gap is opportunities since the same item's preceding presentation (first gap=1). Fit decay in [0,8], spacing in [-2,2]. Sum weighted similarities by label, apply common response exponent gamma (log gamma in [-2,2]), then mix lapse/3 with lapse in [0,.95]. No re-encoding after storage and no learning at test. Eight fitted scalar parameters total.

B, exposure/spacing exemplar: exactly the same prescription with all encoding weights fixed to 1. Its five free nuisance parameters have the identical bounds. P contains B. Thus any P benefit must exceed a baseline with matched exposure counts, exemplar geometry, forgetting, spacing, decision exponent and lapse.

E, empirical generalization map: one label-permutation-invariant conditional softmax regression. For each query and candidate category, use log exposure count, mean-exemplar similarity at fixed c=1/4/16, negative minimum and mean nominal-feature mismatch, smoothed naive-Bayes feature log likelihood, negative last-category age/288 and mean log item gap/log289. Center and scale features using source data only. Fit one common coefficient vector with L2 penalty; choose penalty from .001/.01/.1/1 by leave-one-source-person-out mean NLL. This is one predeclared feature family, not a tournament. It can exploit simple generalization, frequency, recency and spacing without local context encoding.

Fit P/B to pooled source new-item multinomial NLL, equal weight per person (all have24 queries). Use bounded L-BFGS-B from two declared starts: neutral (c=1,gamma=1,decay=0,spacing=0,lapse=.2) and c=2,gamma=1,decay=1,spacing=.3,lapse=.2; P's second start additionally has log encodings [1,-1,-1]. Initialize an additional P run from the best B solution with zero encoding logs to verify the nesting inequality. This numerical check is not a new model. Save every run/convergence status and select minimum source NLL. No evaluation-based tuning, outcome exclusions or model repairs. At most one useful source-only development revision remains allowed under the brief; none has been taken.

## Decisions, uncertainty and controls

Primary outcome: average new-item choice NLL, equal person weighting. Compare P against BOTH B and E. Utility requires >=5% NLL reduction relative to EACH and a strictly positive lower endpoint for EACH paired person-bootstrap 95% percentile gain interval (2000 resamples, seed20261101). Also require absolute difference between predicted and observed pooled new-item accuracy <=.10. This calibration point criterion is not an equivalence confidence bound. Report Brier score, accuracy calibration, individual-person loss differences and deletion sensitivity. No retrospective favorable subgroup promotion.

Before scoring real evaluation responses, save P/B/E probabilities. Quantify disagreement and expected NLL under their own known answer distributions. Generate100 matched-design conditional evaluation controls from saved P probabilities (substantial-signal candidate) and100 from E probabilities (null against the empirical alternative), seed20261102. Apply the ENTIRE same utility rule including bootstrap and calibration to each. Report finite detection/false-pass counts; do not require or imply that merely sampling P guarantees a5% effect. If P's conditional expected advantage is below the utility margin or control detection is low, retain this as a failed discrimination check, not evidence that biological updating is absent. It cannot be repaired after evaluation or by magnifying synthetic effects. Full source-estimation recovery, power at exactly5%, coverage, and population heterogeneity calibration remain UNRUN unless expressly executed within bounds.

Scientific design gate passes only with certified actual item mapping, linked independent people and a genuine source-fixed forecast disagreement. It does not guarantee model payoff. If a defining mapping/chronology fact fails, stop before fitting/scoring and leave stages UNRUN. Source fits may show insufficient useful forecast disagreement and justify stopping without consuming evaluation responses. Save all failed gates and amendments.
