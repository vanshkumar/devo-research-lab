# Reproduction and exposure

Run `python3 -B verify_sources.py` in this directory. It checks the saved response lengths against the observed transfer ledger, joins the OSF project, contributor, provider, file and version metadata, verifies the pinned Git blob digests, and calculates the nominal opportunities, precision scales and body price. It writes [VERIFICATION.json](VERIFICATION.json). The observed check exited 0 and printed the 4,242,799-byte OSF evaluation candidate, 352,400-byte Brown candidate, 74-entry Git tree and 4,595,199-byte combined footprint. The second exit-0 run renamed the two-pass price field for clarity. The scientific scope is metadata arithmetic and static code interpretation.

## Source acquisition

[SOURCE_ACCESS.json](SOURCE_ACCESS.json) contains the exact methods, URLs, output names, per-request caps, status, timings and ingress. [sources](sources) contains the saved bodies and HTTP headers. Direct anonymous requests used local curl 8.7.1 with identity encoding, HTTPS only, no redirect follow, seven-second connection and 18-second overall timeouts. The WMH text requests used the raw Git blob media type and verified each blob’s Git hash and length against the tree. The Li et al. text paths are pinned to commit `c11a292b2f97e2fe9a94d7985e81d70d4af7b8e1`. The sole participant-file request was HEAD for the exact derivative MAT. It returned its headers and zero body. The offline check suffices for reproducing the catalogue result. The original URL data are mutable where the URL uses a branch or index.

Original protocol and sample information came from the [journal publication copy](https://berkeley-deep-learning.github.io/cs294-131-f18/Collins2018_JoCN.pdf) Methods and [author preprint](https://ccn.studentorg.berkeley.edu/pdfs/papers/tortoiseandhare.pdf). The [PNAS supplement](https://ski.clps.brown.edu/papers/CollinsFrank_PNAS_supp.pdf) Experimental Protocol identifies the minimum presentations, criterion, feedback jitter and timeout. The [CF12 article](https://ski.clps.brown.edu/papers/CollinsFrank_WMRL.pdf) Experimental Paradigm gives the predecessor's criterion, bar, clock and explicit instructions. The [UC author manuscript](https://escholarship.org/uc/item/997154n6) Model Fitting/Model Simulation describes the held-block procedure and cross-study simulation. [Bera et al.](https://doi.org/10.1371/journal.pcbi.1014796) Test Phase Validation documents the common softmax over end-of-acquisition values and participant-level calibration analysis. These papers establish documented semantics and prior scope. Exact deployed code and row semantics are separate evidence.

## Exposure and failures

- OSF metadata includes author identity, public license, one provider, one exact file/version, the wiki and empty linked, child and file-metadata record lists. It does not give person identifiers or behavior columns. The WMH tree includes path, Git SHA and size metadata for the full 74-entry index. The decoded author data notes describe the six deterministic files and the family schema. Fitted-parameter and generation-recovery filenames were exposed through the tree.
- The MATLAB source is a secondary analysis/validation contract. Reading it exposed variables, hard-coded fitting and simulation settings, and selection logic. The source was never executed. Actual decoded raw trial values, fitted values, participant-level response summaries, retention rows, and source-only probe rows all total zero.
- Web results exposed incidental published study-level performance statements, selected group test statistics, and figure descriptions for the original and related experiments. The original figure excerpts included the fact that participant points appear in the figure and synthetic task examples. No figure was rendered or extracted and no per-person values were recovered. The resulting contrast is a new prespecified forecast comparison on public archival participants whose broad published findings are known. It cannot claim a discovery insulated from the earlier aggregate results. The query ledger records returned text and envelope sizes. Provider-side body ingress and decode volume are unknown.
- The indexed PMC methods returned CAPTCHA for two papers. An indexed manuscript PDF resolved to an unrelated site, and direct UC find returned an empty placeholder. The original UC manuscript's indexed methods and the author's pinned analysis files provided the missing details. A Nature cookie redirect blocked direct publisher find. These failures and the accessible alternative sources are in the query ledger. There is no outstanding process, transfer or pending review.
