Source defines 784 normalized pixel inputs, three 2000-wide ReLU hidden layers, ten linear logits, zero biases and Kaiming-uniform weights. Standard BP config is 800 tasks, SGD, three candidate steps (.01/.003/.001); CBP uses .003. Every task uses all 60,000 training images once in a new random order and applies a common new pixel permutation to the current already-permuted array. Thus the effective mapping composes across tasks. The loader uses `ToTensor` and saves official test data; training runner binds `x,y,_,_`, discarding it. Accuracy is computed from current pre-update logits on that same training example, not from the test split. Source return files contain metric histories, not the trained model/optimizer/pixel maps necessary to resume a historical learner. In this inspected complete tree, no qualifying source-linked long-history checkpoint was identified. This finite inspection is not proof that no public release exists anywhere.

The scorer can apply the same effective pixel permutation to held-out original test images; it does not need learner access to test labels or task identity. A main comparison must not give learners the known inverse permutation, old-task ID or scorer labels for free. That would change the source information set. Training-example identities, test-example identities, task histories and RNG/model realizations are separate units; many scored images/tasks within one learner are not independent learner replications.
