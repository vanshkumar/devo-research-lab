# Initial development specification

Recorded after START and before computation. This is development, not the main freeze. Six aligned real-valued sensory features (abstract content/timing coordinates), unknown orthonormal nuisance plane U, uniform disk radius R=2, unknown center mu. Tutors Y=mu+Uz+epsilon, z uniform in disk, epsilon iid Gaussian with supplied sigma=.08. Rank2 and noise scale supplied to every geometry/distribution method; raw template methods may ignore them. All receive exactly the same tutor prefix. True corrective error is squared distance to the full finite disk divided by4. Harmlessness is supplied by the experimenter, not identifiable as biological tolerance from repetition.

Plant x=b+Aa, four actions in[-1,1], a*=uniform[-.6,.6], A=VQ+UC (V complement of U, Q orthogonal, C Gaussian scaled .8), b=mu+U(.85R times random unit direction)-Aa*. Thus the mean rendition generally is unreachable, but a* is feasible with zero true error. This actuator coupling is consequential and deliberately constructed, not empirical. Every feedback method uses the same target-blind coordinate pattern search: initial0, 80 complete polls of8axis neighbors, step.5 halved after no improvement, strict tolerance1e-12, all641slots consumed. No actor receives the plant, true target or gradient.

Methods: first tutor; sample mean; regularized rank2 Gaussian quadratic; PCA tangent distance ignoring nuisance range; PCA disk with moment-estimated radius; PCA convex hull of projected exemplars; nearest exemplar; absent constant; same-size wrong-task tutor disk; true finite-disk error. The explicit learned disk evaluator is a simple fitted distribution/support model; its corresponding simple geometric implementation is the same mathematical method, so no separate neural superiority is promised.

FIRST uses three independent development seeds1100..1102, n16, exact scalar feedback, no query noise. Full generated observations, hidden generator/plant and actions/feedback/endpoints are saved before gold scoring. Subsequent development can inspect n3/8/32/128 and change the study once if warranted. Evaluation seeds are not generated before freeze.
