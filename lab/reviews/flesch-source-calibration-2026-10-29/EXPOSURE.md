- Reviewer: native `/root/flesch_source_review`, Sol/max. One local review; no agent, chat, continuation, external message, network request, dependency installation, payment or reset.
- Read governing instructions, registry/current state, task/review briefs, access protocols, timeout amendment, frozen design, masks, source audits/exposure metadata, fit traces/outputs, source forecast/stability outputs and relevant pinned task/model code.
- Materialized only permitted biological archives: all ten immutable input fields in `inputs_only.npz` (600×176×10 = 1,056,000 already-permitted values), and four original source response fields in `source_responses.npz` (600×95×4 = 228,000 already-consumed values). Repeated reads do not create a new holdout.
- Read source-only simulated forecast archives `primary_source_check_forecasts.npz`, `two_start_source_check_forecasts.npz`, and `source_stability_256draws.npz`, including already-consumed observed source curve summaries. Separate invented histories and 2,048 generated 600-event trajectories are synthetic.
- **Zero B2/B20 response values read.** No target omission mask/history, personal/report/vbxi field, combined MAT payload, extractor/reader implementation, historical protected data, Pan prefix/outcome or other HABITS payload was opened or decompressed. The combined MAT filename and access-ledger hashes/counts were visible as metadata only.
- No new fitting, optimizer call, source acquisition or target simulation was run. Independent arithmetic and deterministic re-evaluation of saved source parameters use existing source data only.
- One review compute process at a time; measured maximum RSS 107,347,968 bytes in the final principal check, 55,869,440 in the exact source calculation and 102,154,240 in the boundary/sampler check, below 512 MB. Thread limits were one. No running review jobs remain.
- Numeric audits independently cover the declared finite-correctness primary. The general silent-NaN margin recursion, omission-dependent training-path integration, alternative person family, full 16-case envelope and complete source-refit known-effect/null controls were not established. The raw MAT extraction was deliberately not independently rerun under this review's access boundary.
- Frozen design, masks and input archive were checked against pre-response hashes. Routine source kernel repairs were inspected without editing them; initial diagnostic outputs/failures remain distinct. See `CHECK_FAILURE_HISTORY.md` for a corrected reviewer-test error.
