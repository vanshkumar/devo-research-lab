# Independent review: Flesch shared-rule transport

Reviewed 2026-10-29 by native Sol/max reviewer `/root/flesch_transport_review`. This is a source/code/math review, not a fit or a data-access release.

## Verdict and consequence

**Recommend executing one frozen, source-only design-and-calibration block for the explicitly conditional study; do not retire merely because the cohort is selected.** Do not open B2/B20 responses as part of that block. A subsequent PI decision can authorize a single target evaluation only if the gates below pass. If they do not, retire this route without a model-repair tournament.

The distinct question is whether a completely shared prescription, inferred from B200/Interleaved, predicts acquisition under B2/B20 in the published final-success-selected cohort. This is a real extra constraint beyond separately tuned endpoint fits. It can test predictive sufficiency of that prescription. It cannot estimate acquisition in all recruited people, establish a causal curriculum effect, prove a unique learning mechanism, or rescue the parked mouse route.

**Reliability:** high for the independently checked task structure, original code bytes, model-code availability and selection mathematics; incomplete for actual inclusion bookkeeping, omission feedback, and the model-to-human adapter. **Payoff:** moderate and conditional. No source adequacy, target separation, empirical precision or successful learning forecast has yet been established. The consequential cross-curriculum question remains unresolved.

Material adapter facts from the pinned code:

1. `hebbcl/trainer.py::Optimiser.step` receives input and scheduled reward, performs SGD before Hebbian updating, and never receives a sampled human/model choice. Reward loss is `-sigmoid(logit)*planting_reward`. Thus the published optimizer is choice-independent given its input/feedback stream. This does not establish choice-independent human learning.
2. `utils/data.py` smooths **training** context only; supplied test contexts are unsmoothed. Pandas `ewm(alpha=a, adjust=False)` weights the current cue by **a**, with carryover **1-a**. Do not transplant the source task's illustrative carryover convention into this implementation.
3. `sluggish_runs.py`'s revision blob settings use `gating="oja"`, which updates all input weights in this implementation; `oja_ctx` is a separate context-only path. The revision blob settings also use context scaling 3 versus 4 for blocked versus interleaved. The trees settings use different scaling, rates, layer count and training duration again. A test sharing only the two learning rates would not be a fully shared prescription.
4. Both dataset constructors support only the two endpoint schedules. They center the supplied training inputs and apply a special inactive-context suppression for blocked rows. B2/B20, actual task order, phase boundaries and the initial unknown-context encoding require an explicit sequential adapter. The paper's intended first-task convention must not become an arbitrary per-curriculum switch. A common causal encoding, such as one-hot until the second context is encountered and then centered, is a new declared adapter, not an unchanged published implementation.
5. The primary code uses Gaussian-blob features. Treat their correspondence to perceptual feature coordinates as a representation assumption. Actual image/perceptual transfer is not established here. Downloaded code names image datasets, but none of those datasets or human choice matrices was opened.
6. `train_on_blobs` and `train_on_trees` call the optimizer before their logging probes. Those probes are not pre-feedback human acquisition probabilities. A sequential adapter must emit the current action probability before showing that trial's feedback and updating weights. Preserve the original runner's all-input Oja path as the code-faithful primary unless a separately documented figure-level provenance check justifies another choice; do not silently equate it to context-only Oja.

## Selection and the required likelihood

Let X contain the fixed input sequence and known assignment variables; let Y contain the entire sequence of actions, omissions and the timing category needed for eligibility. Let b be initial weights/person effects, and H_t the full model state. Every model and baseline must define a normalized generative trajectory law

`p_theta(Y | X,b) = product_t q_theta(Y_t | H_t,X_t,b)`,

with H updated using only information the participant receives. X may contain environmental truth known to the analyst; a separate learner-observation projection must hide reward mappings/labels before their feedback. The public schedule is not the same thing as information revealed to the learner: test labels are for the scorer; test feedback is absent.

For the source helper, first set correctness to zero when original RT>5 seconds, remove category-zero trials, and use `nanmean` on trials 401–600. `handleNoResponse` records correctness and RT as NaN. Therefore **NaN omissions leave the helper's denominator; finite late responses count as errors.** The later reshaper does not repair this ambiguity: it changes missing choice to rejection but leaves missing correctness NaN. This distinction matters for both simulated eligibility and learning feedback.

Write K(Y) for retained correct responses and N(Y) for the helper's non-NaN nonboundary denominator. The reported strict event is

`S(Y) = 1{20 K(Y) > 11 N(Y)}`, with an all-NaN test failing eligibility.

With no omissions, N=160 and eligibility requires K≥89; 88/160 is excluded. With two NaN omissions, N=158 and K≥87. An artificial person with 88 correct and two omitted trials passes the helper version but fails an omissions-as-errors version. The actual recruitment filter's relationship to this helper remains uncertified.

For a fixed b the normalizer is the **full trajectory sum**

`A_theta(X,b) = sum_Y 1{S(Y)} p_theta(Y | X,b)`.

For a shared preselection person-effect distribution G_psi, the correct selected-person likelihood is

`p(Y | X,S;theta,psi) = 1{S(Y)} [integral p_theta(Y|X,b) dG_psi(b)] / [integral A_theta(X,b) dG_psi(b)]`.

The denominator is outside the mixture. Averaging individually truncated person laws against the original G instead assumes a different sampling population. Selection reweights person types by A(X,b), differently in each curriculum. A synthetic two-type, three-trial example gives probability 0.179487 for trajectory 110 under the correct ratio, versus 0.207792 under that wrong average; the strong type's selected share changes from 0.5 to 0.717949.

Do not apply a Poisson-binomial tail to marginal correctness probabilities for a history-dependent model. Exact enumeration and an independent finite-state recursion agree in a four-trial response-persistence witness: P(S)=0.4545, versus 0.3125 from independent Bernoullis with the same marginal 0.5 probabilities. In the original choice-independent optimizer, an independent test calculation can be valid **conditional on** frozen weights, an independently specified omission process and no response-history decision term. Integrating person effects, adding perseveration, or allowing omissions to affect training invalidates the blanket simplification.

For a training-trajectory-only score, the correct selected density is `p(Y_train|X)*P(S|Y_train,X)/P(S|X)`, integrating latent state appropriately. Selection on future test success changes the expected earlier acquisition curve. Boundary trials omitted from accuracy still advance context/response history and cannot be deleted from the simulated timeline.

Missing excluded IDs/counts do **not** prevent calculating these conditional laws or evaluating a fixed selected cohort. They do prevent recruitment-rate estimation, unrestricted population statements and checking the selection mechanism. An unrecorded outcome-dependent filter Q would require conditioning on S∩Q. No finite credible envelope for arbitrary Q is available. If actual inclusion cannot be reconciled with a declared rule or an observed pre-training filter, stop any sampling/population interpretation. A fixed-export predictive benchmark remains definable, but it must be labeled as such rather than claimed as a sampled `S`-conditional population result.

## Choices, feedback and indispensable unknowns

Valid acceptance receives the scheduled planting value and rejection receives zero; both chosen and unchosen numeric values are displayed in training, as also documented in the primary reanalysis. Hence rejected trees do not hide the planting value. Updating from full counterfactual training feedback is defensible; supplying true category before feedback or at test is not. The distinction between expt_rewardIDX and resp_reward is essential. A chosen-reward-only model is a different information-use assumption, not the same supplied teacher.

No-response handling writes missingness and zero received reward but does not itself invoke the accepted/rejected feedback paths. The exact timeout transition/display path was not newly acquired. Carry two explicit alternatives until certified: omitted training trials supply no supervised update versus retain the displayed full-feedback update; cue integration can still proceed if the stimulus/cue was seen. Apply identical omission semantics to baselines. Do not silently use actual target omission masks.

Other indispensable checks before a scientific target score: actual column-to-curriculum mapping and phase chronology; whether the export satisfies the asserted criterion; exact instruction branch and pauses; action coding; a selection-aware person-effect/initial-state model; and source-only predictive separation. Allocation randomization is not established. B200 instructions differ from B2/B20/Interleaved, so transport is across the complete known training packages, with an instructional confound for causal interpretation.

`vbxi_category` is a possible initial-state channel. The already-read parameter file only initializes it; the analysis README names grid-prior analyses, and the association is already published. Its exact field mapping and pre-training timing were not independently certified from the copied files. No values were opened. Use it only after code/chronology certification and a frozen source-only transformation; do not advertise the existing association as a new discovery. Do not use `subAcc`, reports or personal fields as input.

## One smallest defensible study design

Freeze the following before any responses. This review recommends the design work; it does not authorize the reads.

**Access and split.** B200/Interleaved are source; B2/B20 are the sole target. First extract only original input fields and anonymous column indices; infer schedules from inputs and cross-check assignment metadata safely. Permit the source response/RT/correctness fields only after a reader proves column-specific masking on synthetic MAT fixtures. A generic `loadmat` of the combined 176-person file would expose targets. Record compressed acquisition, inflated-but-discarded bytes, decoded columns and scientific exposure separately; any necessary blind decompression/discard of target payload needs an explicit PI access decision. Never claim zero target payload inflation if the stream implementation performs it. No personal identifiers, `subAcc`, or later reports are needed.

**Models.** Keep three prescriptions, with one common hyperparameter/person-effect distribution and no target fitting: (1) the pinned combined model with shared SGD/Hebbian rates, context scaling, sluggishness, representation and decision-noise/omission rules; (2) a context-separated linear error-correcting value learner with full revealed feedback and cue/response persistence confined to its decision stage; (3) a difficulty-aware exposure-growth/decision baseline with shared growth parameters, context-specific exposure counts and the same sensory/action/omission information. The growth decision map must be learned from revealed training feedback; it must not receive hidden future labels. Give all models identical original schedules and known instructions. The persistence baseline is a meaningful rival prescription, not an assertion that sluggishness and Hebbian gating exclude one another. A no-Hebbian ablation can explain a failure but is not a fourth primary candidate. Do not use published group-specific rates or context gains as target defaults.

**Fit and generate.** Fit selection-aware source laws, preserving individual heterogeneity and known counterbalancing. Use whole-person held-out source checks and both source groups; do not choose a model solely from a pooled source mean. Freeze all parameters/uncertainty, initial-state distribution, adapters and seeds. Generate complete new-person trajectories from trial 1 through 600 on each target schedule, then condition on the same eligibility event. No actual target histories, choices, omissions or rewards may be supplied to forecasts. Person-level source fitting may evaluate observed histories in a joint likelihood; that is not a replacement for autonomous target rollout.

**Observables and scoring.** The primary autonomous observable is opportunity accuracy across eight fixed 50-trial training windows, counting nonboundary omissions as failures, even if the selection helper drops omissions. Freeze a multivariate energy score for that generated curve vector, averaged equally over people and then over the two target curricula. It respects joint simulated dependence; do not score bin means as independent binomials. Require the combined prescription to outperform each strong baseline with a person-level uncertainty interval and report absolute curve error/calibration separately. Prespecify switch-lag×congruency error summaries and the complete no-feedback test choice geometry as secondary checks. Use input-defined feasible lag bins, since B2 has no within-run lag>2. Final-test success alone is not a discriminating endpoint after selection. A joint selected-trajectory log score is useful secondary evidence, not a substitute for generated-curve performance.

**Known-effect/null gates, source only.** Simulate entire cohorts, initial/person effects, omissions, recruitment selection, fitting, model choice, forecast generation and scoring at the actual input-derived group sizes. Include generators favoring each main prescription, a growth/no-order-effect null, and matched null forecasts; rerun the full source fit in every calibration replicate. Propose a useful 5-percentage-point acquisition-curve separation sustained for at least 100 nonboundary opportunities as an explicit design investment boundary (one extra correct per 20 opportunities), not an estimate from these data. Freeze the final threshold before source outcomes and do not loosen it after target access. Require at least 80% sensitivity for those declared known-effect generators and at most 5% false preference under the matched null, with Monte Carlo uncertainty sufficient to assess those cutoffs; otherwise stop. This is generator-specific calibration, not universal power. Include both source groups' person variability, counterbalancing, common instruction/cohort shifts and between-initialization variation; simulation error is separate from participant/environment uncertainty.

**Finite sensitivities.** Predeclare a bounded grid: helper versus omissions-as-errors selection; no-feedback versus full-feedback on omitted training trials; published unsmoothed test cue versus continued cue integration; and a continuous versus a two-component source-fitted person-effect family. This gives 16 transparent combinations, not a search for a favorable result. Add only one prespecified common-versus-known-instruction-branch initial-state sensitivity if source evidence supports it. All parameters/ranges come from source-only fitting or explicit code alternatives. Require the scientific decision to survive this envelope; otherwise report dependence and stop. These families cannot bound arbitrary unseen exclusion filters or arbitrary target ability shifts. Those are conditions on the claim, not nuisance parameters to tune away.

The strongest surviving objection is that this adapter/selection/heterogeneity envelope may erase source-only separation or leave different plausible prescriptions predicting the same B2/B20 curves. Then opening targets would yield another calibrated benchmark with little mechanistic payoff. **The stop condition is real:** if a common prescription does not fit source groups, if selection/safe extraction cannot be defined, or if the full pipeline cannot distinguish the declared meaningful effects under the finite envelope, retire before target responses. No empirical target effect or precision is asserted by this review.
