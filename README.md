# Devo research lab

A research archive of computational and empirical investigations into learning, behavioral forecasts, sensory teaching, and simulator validation, conducted October 28 through November 6, 2026.

**The lab is paused at a human-requested resource stop. Its broader scientific mission remains unfinished.** Completed studies include a conditional mouse-forecast accuracy limit, a positive human forecast under known schedules, synthetic sensory teaching, a quantitative hypothalamic transcript assessment, and bounded model counterexamples. Each finding has substantive limits.

Start with the [scientific and process retrospective](RETROSPECTIVE_2026-11-06.md). Future lab agents should also read [LEARNINGS](LEARNINGS.md), current [STATE](STATE.md), and the relevant original report and independent review. [REPORT](REPORT.md) indexes the early campaigns; [lab/tasks](lab/tasks) and [lab/reviews](lab/reviews) contain later work.

The [public archive scope](PUBLIC_ARCHIVE.md) explains excluded data and runtime files. This repository is an inspectable research record, not a turnkey dataset distribution. Reproduction may require separately obtaining pinned public inputs and respecting each study's access and exposure conditions. Historical absolute paths and native chat links refer to the original local workspace.
