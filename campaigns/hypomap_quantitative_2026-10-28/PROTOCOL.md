Compare a dominant-program-plus-background model with one permitting a mixed component. ## Conditional non-peptide prediction

If a substantial tail exists in several useful donors, evaluate whether target peptide abundance groups can be predicted in held-out donors from other genes. Primary labels use the operational definition above; a threshold-grid sensitivity is explicitly secondary. Exclude OXT and AVP from features, size factors and all feature-selection statistics. Candidate-only evaluation is primary so cluster identity cannot trivially solve the task. Comparison-population classification is exploratory and labeled separately.

Use leave-one-donor-out evaluation, training-only normalization/feature filtering/scaling/selection and a regularized linear classifier. Select regularization within training donors when feasible; otherwise fix it and disclose. Report every donor's class counts, ROC AUC, balanced accuracy and log loss; undefined metrics remain undefined. Baselines: training class prevalence and measured depth/quality/source covariates. Donor labels cannot be predictor features. Evaluate cross-study training/testing, source-restricted results and depth/quality-matched or residualized sensitivity where feasible. Record marker direction consistency with feature selection restricted to training donors. Grouping by peptide counts is not itself evidence that other genes independently predict that grouping.

Null controls must preserve source/donor/depth structure (permute labels within donor-depth bins), repeat the complete selection pipeline, and report null distributions. Inject known non-peptide signatures at observed noise/depth to show recovery range. Include synthetic doublets in sensitivity tests. A held-out signature alone does not prove a discrete cell type, and training donors also contributed to the historical cluster selection.

## Decision and validation

Promote only if substantial signal is present in >=2 adequately sampled donors from each source study, with >=20% and >=10 substantial cells in each supporting donor under the primary definition, remains material at k=20/r=.10, survives depth/quality controls, and cannot be readily recreated by the declared plausible artifact scenarios. These operational criteria are deliberately conservative nomination criteria. A reproducible non-peptide signature strengthens promotion but cannot rescue trace counts. Report exact outcomes even if they fall just below a criterion. If signal is overwhelmingly tiny, confined to one source/donor, or readily explained by quality/doublet patterns, deprioritize. If competing artifact scenarios still span the result, quantify residual ambiguity and the discriminating measurement.

Independently reproduce at least one decisive extraction/statistic using a separate implementation from original matrix bytes. Use observed-depth injected-signal and false-positive controls to validate the scientific comparison. Commission an adversarial numerical/scientific review before final synthesis. Model agreement is not independent empirical confirmation. Finish after the informative measurement, warranted signature/technical follow-up and review; no cosmetic analysis queue.
