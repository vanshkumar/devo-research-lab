# Technical implementation decisions

Recorded before this agent inspected the newly extracted peptide abundance outcomes (2026-10-28). The campaign protocol remains primary.

- Background comparisons will retain nearby Mid-3, other neuronal and non-neuronal pools separately; within each donor, match 100 nearest cells in log non-peptide depth, or all available if fewer. Report mean and upper-quantile empirical rates, exact exposure totals and Poisson/NB tails for 1/2/5/10/20 multipliers. Upper quantiles include genuine expression and sampling noise and are sensitivity scenarios, not ambient estimates.
- The transparent predictive comparison fixes AVP as the secondary outcome in the OXT-named candidate, rather than defining the response as the smaller observed count and silently fitting an untruncated count model. OXT and non-peptide depth are observed conditioning variables. Null mean is background-rate × non-peptide-depth × multiplier + beta_trace × OXT, beta_trace bounded 0–.01. A mixed component adds a ratio in [.10,10] with regularized prevalence. Both use negative binomial noise; nuisance parameters are trained using other donors. Source-specific background rates come only from the training donors' controls. Background dispersion and broad heterogeneity remain explicit sensitivities.
- Primary model uses weak regularization of contamination multiplier toward 1 (log-scale SD log5), dispersion toward empirical control dispersion (log-scale SD 2), and mixed prevalence toward small values via Beta(1,4). Model comparison is held-out predictive log density by donor, not a likelihood-ratio p-value. Null and mixed simulations at observed depths run the entire donor-held-out fitting process. Model preference cannot certify biological mixing because a broad residual contamination process may fit the same counts.
- Doublet sensitivity uses actual opposite-dominant peptide profiles from the four prespecified groups, with pure-parent criteria >=10 dominant counts and minor/major<=.01. Generate same-donor 25/50/75% mixtures, both summed-library and target-depth Poisson-resampled profiles. Exclude OXT/AVP from doublet-classifier features and normalization. Evaluate synthetic-vs-parent classification on held-out donors before interpreting candidate scores. These controls assess this particular synthetic-doublet family, never a universal doublet detector or artifact rate.
- Primary source QC metadata use inconsistent mitochondrial units across studies according to provenance review. Use within-donor ranks and actual count-matrix depths; any cross-source mitochondrial feature will be recomputed from MT-* count columns.

## Post-outcome refinement, before model fitting

The target has only two primary substantial cases (both znZv1), and a reverse-dominant observation OXT14/AVP1265. A fixed AVP response on all cells would mischaracterize that reverse-dominant observation as extreme mixing. Therefore the main model conditions on the observed dominant gene identity and its count M, models the minor count m with its gene-specific background rate, and divides each NB probability by its CDF at M (explicitly truncating at m<=M). In this conditional model the mixed mean ratio is bounded [.10,1], changing the initial fixed-AVP [.10,10] plan because the response is now minor relative to major. The primary conditioning model is descriptive, not a likelihood for the full two-gene generative process. A fixed-AVP/OXT-dominant-only sensitivity is retained and must also truncate at AVP<=OXT. Both competing models use identical conditioning; injected signals are generated under that same model and separately through untruncated count injections and synthetic doublets.

The contingent non-peptide signature is not supported by a multicohort substantial tail, so a complex synthetic-doublet classifier with only two target positives would be misleading. Doublet analysis instead tests how often realistic opposite-program parents produce threshold-qualified abundance at observed depths and whether the rare two cases have grossly doublet-like non-peptide complexity. This cannot classify the rare cases as genuine or artificial.

## Diagnostic failures and corrections

- An initial doublet run used Series.T for the column named T; pandas interpreted this as transpose. It failed before generating outputs. The exact error remains in logs/technical_doublets_initial_failure.stderr. Corrected to bracket indexing and rerun successfully.
- Independent reviewer correctly noted that the first fixed-AVP sensitivity omitted its selection truncation. Original outputs are retained with `initial_invalid_sensitivity` suffix and are excluded from inference. Corrected both fitting and scoring to use the conditional CDF normalization and reran. The symmetric primary model always used truncation.
- Empirical nearby-control overdispersion was extreme. Training-fold reference shapes were 0.076507–0.101999; the separate control/mixed simulation generator used shape0.1409951190, and its additional null used shape0.5. Recovery under those explicitly recorded generator distributions failed to distinguish injected mixed components reliably; this failure is preserved. Additional outcome-informed diagnostics use moderate NB shape10 and non-neuronal control rates to establish whether the model can discriminate in a less dispersed regime. They do not repair uncertainty about the real nuisance process. Generator, training-reference and fitted shapes are distinct quantities.
- Direct count-injection recovery includes all cells in each of the five adequately sampled donors, including four peptide-zero znZv1 cells. Conditional-model fitting necessarily excludes M=0; those model denominators must not be conflated with detection denominators.
