# Sources and protected empirical inputs

2026-10-28. This focused campaign uses public processed observations; no controlled reads, author contact or private upload.

1. **Current quantitative source:** [HYPOMAP CELLxGENE collection](https://cellxgene.cziscience.com/collections/d0941303-7ce3-4422-9249-cf31eb98c480), dataset version `af06d70d-a2bc-43c1-8378-bc545bc8ee2c`. [Public H5AD](https://datasets.cellxgene.cziscience.com/af06d70d-a2bc-43c1-8378-bc545bc8ee2c.h5ad). Actual HTTP206 bytes, Content-Range, ETag, S3 version and SHA256 are preserved in `inputs/range_cache/`, indexed by [acquisition_manifest.json](inputs/acquisition_manifest.json). [PROVENANCE.md](PROVENANCE.md) specifies dataset/collection versions, resource use, failures, exact sparse extraction and the incomplete upstream curation chain. No whole-file digest is claimed.
2. **Historical snapshot and source code:** [author repository at29599fcb](https://github.com/lsteuernagel/HYPOMAP/tree/29599fcb13a74a908c986ad69d68fc3e4a3cf6d0). Original tables remain in the preceding campaign. All415 neuronal names/sizes reconcile, while the publication's413 scope remains distinct. Current barcode roster was inspected; exact historical barcode equality is unavailable. Source-code locations and checked Git-blob/SHA256 evidence are in [source audit](experiments/provenance_review/REPORT.md) and its code manifest.
3. **Primary atlas:** Tadross et al., [Nature2025, DOI10.1038/s41586-024-08504-8](https://pmc.ncbi.nlm.nih.gov/articles/PMC11922758/). Inspected relevant Methods and Results: Tadross CellBender/scDblFinder, imported Siletti data, cluster naming, and C4-296 AVP/TFPI2 with OXT. This source does not provide a current count-correction uncertainty per cell or validate joint OXT/AVP in C4-313 by an orthogonal assay.
4. **Siletti upstream processing:** [adult-human-brain source](https://github.com/linnarsson-lab/adult-human-brain/tree/2b5aa12dffb8cc1bcb3979c409cb6ac907546b2e). Inspected QC/processing code establishes that MT_ratio is fractional. Independent numerical reconstruction confirms the mixed exported mitochondrial units. Different upstream count processing is preserved as a limitation; common CellBender correction is not assumed.
5. **Conversion semantics:** [SeuratDisk Convert documentation](https://mojaveazure.github.io/seurat-disk/reference/Convert.html), h5Seurat→H5AD mapping. Supports counts in raw.X when scale.data is absent, combined with author export code and actual integer-value checks. It does not supply the missing final CELLxGENE curation history. Six-row X audit separately establishes the stored log-normalization denominator.
6. **Quantitative precedent:** Xi, Kusano & Gainer1999, [primary PubMed abstract](https://pubmed.ncbi.nlm.nih.gov/10499525/), DOI10.1210/endo.140.10.7054. Preserved primary NCBI XML in provenance_review. Rat single-neuron competitive RT-PCR found unequal dominant/minor means256 and182, with one approximately2:1 mixed neuron. Abstract-only access; different species, preparation and assay prevent direct numeric calibration to human nuclear counts.
7. **Recent related characterization:** Li et al., [Cell Reports2026 primary indexed text](https://pmc.ncbi.nlm.nih.gov/articles/PMC13007250/),45(2):116904, and [2025 preprint](https://pmc.ncbi.nlm.nih.gov/articles/PMC12633530/). Human comparison reuses Siletti/Tadross and is not independent replication. Mouse joint-peptide/Esr2-Abcc9 evidence limits broad novelty claims; it does not identify this human candidate as the same state. Relevant indexed primary text was inspected; direct PMC browser checks were not bypassed. Version and access qualifications are in the source audit.

Older in-situ/ambient-RNA sources remain documented in the [preceding atlas source record](../byrnes_todo_2026-10-28/experiments/atlas/SOURCES.md); this campaign does not claim to have independently re-inspected all those papers. Primary findings here arise from the protected count subset, not from literature authority.
