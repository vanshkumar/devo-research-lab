# Close-prior and contrary-evidence audit

2026-10-28; completed bounded source audit. Read root LEARNINGS.md and charter. This file records inspected primary material, source versions, and limitations. No external contact, paid access, or accounts used. Prior campaign files were not changed.

## Main corrections to the starting interpretation

1. A detailed motor-construction competitor already exists: Mackevicius, Happ & Fee (2020), DOI10.1038/s41467-020-18732-x. Its NIf/HVC sequence model explicitly addresses Zhao2019 stimulation outcomes. Therefore neither the motor-coordinate explanation nor an onset-rhythm confound is a novel discovery here. Our potential contribution must be a checked model comparison or measurement limit beyond that prior model.
2. The 2026 Fee seminar is not the only primary source for cooling during tutoring. Andrew H. Bahle's May2024 MIT PhD thesis, *A neural clock underlying the temporal dynamics of an auditory memory*, is identified in the official repository, handle1721.1/156934. COSYNE2023/SfN2023 and AREADNE2024 contain earlier author-attributed abstracts. Full thesis acquisition remained blocked by HTTP429 after honoring the repository’s15-minute Retry-After and one bounded retry; no quantitative juvenile conclusion was established from the thesis.
3. Cooling-direction agreement would identify temporal encoding dependence, not prove that a memory is later used as a comparator. A comparator written in HVC coordinates and a motor chain whose extent is written in those coordinates both predict the same adult duration after return to normal temperature.

## Closest model: exact source and reproduction cautions

Mackevicius2020 Methods specifies: rhythmic four pulses spaced10 model steps (100ms); sporadic single pulse; inter-trial intervals Poisson λ50 steps,min27;7200 trials. Post-training single-pulse readout repeated10 times/run should estimate activity duration. HVC base model is Okubo2015 (reference40). The combined NIf/HVC model filters NIf input to onsets. Root is separately auditing and executing the supplied source implementation; code and paper must not be presumed identical.

Model source provenance: publisher supplement is52,620,152bytes. Initial capped whole-file attempt transferred12,000,001bytes then stopped. Public HTTP206 range extraction fetched129,024bytes and verified CRC/size of38 code/text members. `mackevicius_range_manifest.json` records exact ranges, headers, member hashes; `mackevicius_zip_directory.json` records full directory. `trialTimes.mat` additionally fetched12,697bytes and CRC-verified. This is a code subset; no whole-archive hash is claimed. Original MATLAB source remains unmodified.

Peer-review PDF pages3–4 discuss offset coding and arbitrary switch from anti-Hebbian to Hebbian learning. Authors' response and final paper clarify choices, so unresolved early-review comments are not treated as proof of final errors. Pages19/22 explicitly note incomplete reproduction of stereotyped motif organization. Pages21–22 clarify that within-HVC connectivity changes drive the chain model and that the same cells were not followed until tutor syllables were copied. These constrain claims of empirical identity between sensory and motor representations.

## Later empirical constraint on the sequence-construction account

[Mackevicius et al.2023](https://elifesciences.org/articles/77262), DOI10.7554/eLife.77262, Results “Tracking HVC sequences across rapidly learned song changes” and Discussion, observes sequences before tutor exposure and follows their association with new syllables after exposure. Four learner birds have pre/post sequence correlations0.20,0.38,0.27,0.45. A complementary analysis extracts sequences exclusively before tutoring then tracks them forward, addressing post-tutoring selection. This is a constraint on models requiring tutoring to create every sequence de novo, not proof that motor structure alone suffices to store the target. The authors explicitly interpret relatively stable sequences through song changes as compatible with reinforcement learning and less compatible with a strict inverse model that rearranges premotor firing order. Public data/code are declared at Dryad DOI10.5061/dryad.j0zpc86km; not downloaded in this bounded audit.

## Stronger evaluation-related intervention

Roberts2017 Fig6 (PDFp7) reports slower temporal reinforcement learning in4/5 birds and impaired temporal recovery in5/5 after noise ceased (recovery: paired t4=4.8,p=.008). Pitch learning/recovery was preserved. Thus this is not a selective recovery deficit: impaired temporal plasticity or a permissive correction pathway could explain both timing effects. Methods(PDFp11) defines timing as syllable onset-to-next-onset, including syllable+gap. Same birds were tested before and ≥3weeks after caspase; post-lesion recovery monitoring continued5–10days longer. Adult setpoint recovery does not identify storage or establish the setpoint as the juvenile tutor target. Juvenile ablation separately impairs imitation, without isolating acquisition from sensorimotor copying. Data are available on request; none requested. Full author PDF was inspected via web; direct download failed PDF-validation, leaving no verified local PDF.

Long/Fee proof pages1–2 were rendered and visually inspected; plots/text agree with the frozen adult calibration. Files `long_proof_page1.png` and `long_proof_page2.png` preserve the visual check.
