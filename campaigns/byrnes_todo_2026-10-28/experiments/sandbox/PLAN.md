# V1: minimal intervention tests for proxy-vs-welfare values

2026-10-28, pre-outcomes. Source question§3.1 asks what sandbox tests are possible/useful. Execute an exhaustive finite policy-family example rather than build an orchestration platform or simulate AGI. Primary prior work: AI Safety Gridworlds(2017), goal misgeneralization(Langosco2022). No novelty claim.

Three outcome features: actual recipient welfare W, visible pleasure signal P, evaluator approval A. Candidate linear values have nonnegative integer weights summing10(66 weight vectors). Utility-maximizing choice among3 actions, deterministic tie-break. Calibration/training tasks align W=P=A, so all policies should choose genuine help. Candidate intervention tasks independently change welfare, pleasure cue and approval; enumerate all distinct 3-action menus from feature outcomes in{−1,0,1}³, bounded selected menu family if all combinations excessive. Known-control pure-welfare policy must choose maximal W; deliberately proxy-only policy must be caught when proxies are clamped or misleading.

Question: does a small held-out intervention battery exclude the training-compatible policies that sacrifice welfare in some known menu? Enumerate all66 policies, all pair menus(351), count agreement/equivalence classes and find a small greedy separating set. Independent exhaustive checking of the final selected test set supplies its actual coverage within the class; keep untested mixtures/agent algorithms outside claim. Tie choices are reported; inspect effects of small utility margins/continuous weight refinement as adversarial check if promoted.

Output is a worked, runnable test specification and exact coverage result, not empirical evidence about a trained agent, internal values, human compassion or AGI safety. If passing policies still differ on withheld cases, preserve that failure. Training and test policy-family construction is explicit, so no claim of blind or independent model validation.
