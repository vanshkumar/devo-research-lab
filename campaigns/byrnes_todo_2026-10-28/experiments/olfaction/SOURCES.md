# Source provenance

Retrieval/inspection date2026-10-28. `data/olfaction/manifest.json` stores exact official query URLs, byte counts and SHA256. Raw responses retain metadata and every returned row. No image volumes downloaded.

- [Allen SDK unionize definitions](https://alleninstitute.github.io/AllenSDK/unionizes.html), Record Properties table: density, normalized volume, compartment and hemisphere definitions. [Official example](https://api.brain-map.org/examples/doc/thalamus/download_data.js.html) and [official query implementation](https://github.com/AllenInstitute/AllenSDK/blob/master/allensdk/api/queries/mouse_connectivity_api.py) inspected for legitimate API models. `Structure/query.json` graph1 validates IDs; `ApiConnectivity/query.json` provides injection metadata; `ProjectionStructureUnionize/query.json` provides measurements. API is live, not a release-pinned atlas; saved bytes define this run.
- [Bader et al.2012](https://www.frontiersin.org/journals/neural-circuits/articles/10.3389/fncir.2012.00084/full), Results on DiI projections and WGA labeling, Figures3–6, and Discussion on labeling direction inspected in full relevant HTML. Specialized OR37 tracing supports a hypothalamic route and AVP-associated labeling. DiI direction and transsynaptic WGA interpretation require care; these tools alone should not be described here as unequivocal functional monosynaptic proof. This is positive prior evidence, not contradicted by our insensitive aggregate assay.
- [Russo et al.2018](https://pubmed.ncbi.nlm.nih.gov/29845448/), DOI10.1007/s00221-018-5298-z, abstract only inspected. Reports retrograde tracing related to ghrelin-expressing olfactory neurons and hypothalamic/amygdala targets. Full methods were not verified, so this remains a lead, not a reproduced result.
- [Oh et al.2014](https://www.nature.com/articles/nature13186): attempted publisher access redirected to identity service; not used for detailed claims. No bypass attempted.
