# Atlas pilot plan — 2026-10-28, before downloaded table outcomes

Question (§2.5 of Byrnes to-do list): can published human–mouse hypothalamic cluster matching nominate specific social-signalling populations, and how much ambiguity does naming a marker hide? Use the actual HYPOMAP summary tables, not a synthetic demonstration. The theoretical framework is a question source, not an accepted neural partition.

Material: Tadross et al Nature2025 DOI10.1038/s41586-024-08504-8; pinned lsteuernagel/HYPOMAP commit29599fcb13a74a908c986ad69d68fc3e4a3cf6d0. Retrieve published cluster annotations (~0.3MB), matching table (~0.1MB), correspondence table(~.05MB), full all-cluster marker table (~16.6MB), sample statistics and relevant matching/supplement code. Cap100MB. These are author-derived summaries, not independently processed raw cells.

Predeclared target genes: OXT, AVP, OXTR, AVPR1A, ESR1, GAL, PRLR, TAC1, TAC2. They nominate signalling/population candidates, not specific social function. Known identity controls: POMC, AGRP, HCRT and source-described AVP/OXT region. Determine all table schemas, filtering and levels before results. Do not call missing marker rows absent expression.

Test: restrict to granular neuronal human C4 clusters as actually available; reconstruct all published mouse partners, best versus alternative partner scores and match categories. Identify marker-positive candidate clusters from the full marker table using source filters; compare all positive marker rows vs fixed top5/top20 rank sensitivity without tuning. Report candidate-by-candidate mappings and how naming the cluster by a gene overstates a single exact cross-species counterpart. Control: recover named POMC/AGRP/HCRT populations and source-known matching cases; independently verify join key and record coverage/unmatched rows. If controls fail, target interpretation is inconclusive until repaired.

Expected interpretations: a unique high correlation is candidate correspondence under this pipeline, not conserved receptor function/social behavior; multiple partners or hierarchy sensitivity limit which circuit experiments can be transported across species. Marker cohorts are overlapping nonindependent cluster groups, so no cell/frame-based p-values or human–mouse population inference. A human-only receptor signal needs direct matched expression/donor checks unavailable in filtered marker summaries. Do not claim it from marker absence. Donor coverage in summary tables is descriptive, not an independent expression validation.

Outputs: acquisition manifest with sizes/SHA256/Git blob checks; runnable analysis; full target/control rows, matching statistics, known-marker checks; NOTEBOOK/SOURCES with exact source locations, limitations and keep/revise/retire decision. This is one substantive pilot unless a genuinely different question receives its own pre-outcome design. No full cell atlas, account, EGA data or private upload.
