# Bounded two-state efficiency challenge: development-only

Frozen before state-model fits, 2026-10-28. Source controls and the lead's development observable (-0.113 degrees, SE0.205) are known. Reserved and external outcomes remain sealed. This model does not replace the primary observable test or its0.2-degree margin.

Two parallel states generate compensation-positive endpoint y=-Hand_raw. Both have shared baseline retention parameters a_fast in[0.10,0.85], a_slow in[0.86,0.995]. The restricted model has fixed retention. The alternative changes only fast-state retention on zero-clamp spatial-jump trials to a_event in[0.01,1.35], with delta=a_event-a_fast. All realized sequences remain long-run contracting in this range; a transient transition above1 is permitted. This is one additional nonlinear parameter and permits both modulation signs. The initial informal plan contemplated a common multiplier on both states; using one fast-state parameter instead matches the existing known-generator challenge and avoids confounding a positive effect with unstable slow-state growth. No state-model outcome has been fitted before this refinement.

For each person, both models receive identical flexible linear nuisance: eight input-cell contrasts per state (reference zero-clamp/no-jump), eight direct current-cell endpoint contrasts, four portion intercepts, four linear drifts, and two initial-state amplitudes per portion. Thus people can differ in learning gains, direct effects, drift and initial state without treating their earlier measured reach as an error-free latent state. Initial amplitudes make the portions conditional on unobserved prior state without bridging deterministic probes. All180 randomized trials in each portion are represented; history is never joined after missing endpoints. Finite endpoints with abs(y)<=90 enter the fit. Cells omitted by a particular source cannot be invented.

Variable projection solves all linear nuisance by least squares for each nonlinear parameter vector; bounded optimization profiles the shared retentions. Modest prespecified starts are(0.35,0.90),(0.65,0.97),(0.80,0.99), with alternative initialized from the selected restricted fit and two signed event shifts. No other model family is selected. Fit quality and parameter/observable stability are descriptive development evidence.

The model-implied older-input curve is half the difference between prior stationary +4 and-4 gains, multiplied by delta and the actual future transition products. Report equal person/set means for lags1–5 and stationary-readout subsets. The isolated future-zero/no-jump curve is also reported, but it is not substituted for the actual-schedule estimand. Direct endpoint nuisance cancels from this counterfactual contrast.

Freeze set-average gain/direct/drift/initial-state coefficients and nonlinear parameters for later reserved prediction. Only baseline mean calibration is allowed for a new person's level prediction. Prediction scores will use the same fixed-pre-five contrast as the primary analysis; no validation fitting of state coefficients or retentions is allowed.

Known-generator tests use actual development schedules with fixed-retention current-gain effects and signed fast-propagation effects. Check noiseless recoverability first, then correlated motor/observation noise, drift and person variation on a small balanced development subset. Conditional person t intervals are explicitly conditional on fitted shared nonlinear parameters; whole-fit participant bootstrap, if executed, supplies a separate uncertainty check. State/perceived-error storage interpretations remain observationally equivalent as already documented in the source audit.
